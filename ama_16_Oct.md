# AMA Questions and Answers

## How do you generate an API key?
### Answer:
- Open Claude Console
- Open API keys
- Create your key
- Copy and save the key

## What are tools?
### Answer:
Tools in Claude are functions or capabilities that enable Claude to perform specific actions, such as searching the web, executing code, reading files, or interacting with external APIs. Claude can select an appropriate tool, receive its results, and use them to generate a more useful response.

## What are the three ways to collaborate with AI?
### Answer:
The three ways to collaborate with Claude AI are Automation, Augmentation, and Agency. These describe how AI can perform tasks, collaborate with humans, or work more independently toward a defined goal

## What is the difference between asking AI to write code and using Claude Code?
### Answer:
- Asking AI to write code means using an AI assistant to generate code from a prompt. 
- Claude Code is an agentic coding tool that can interact with a codebase, modify files, run commands, test implementations, and debug problems. It helps automate more of the software development workflow, while the developer remains responsible for reviewing the changes.

## What is an MCP server?
### Answer:
MCP server stands for Model Context Protocol server. It is a program that allows AI applications, such as Claude, to connect to external tools, data sources, and services through a standardized protocol.

## What is tokenization?
### Answer:
Tokenization is the process of breaking text into smaller units called tokens so that an AI model can process and understand the text.
