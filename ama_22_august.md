# AMA Questions and Answers

## Q1.  What is the difference between Git and GitHub?
Ans:-   Git is tool which is used to track our folder or work and Github is a platform by which we use git. 
## Q2.  What is the difference between DROP, DELETE, and TRUNCATE?
Ans:-   
- Drop: It is used to delete the table from database.
- Delete: It is used to remove a particular record from the table.
- Truncate:- Its removes all the record from the table permanently without  changing the structure of the table.
## Q3.  What is abc?
Ans:-   In python abc is a module by using it we can create an abstract method in a class by using @abstractmethod annotation.
## Q4.  What are file permissions?
Ans:-   There are three types of file permissions read, write, execute we can set these permission to every file or directory by using chmod command for user, group, other owners of the file or directory.
## Q5.  Which command is used to move a file from the staging area back to the working area?
Ans:-   git restore --staged file_name.
## Q6.  What is the nano command?
Ans:-   nano is text editor so, by using nano we can edit of write in a file.
## Q7.  What is MRO, and why is it used?
Ans:-   MRO stands for Method Resolution Order. In Python it is used to decide which class method to run first when a class inherits from multiple parent classes.
## Q8.  Which flag is used to save changes in sed?
Ans:-   sed -i file_name
## Q9.  What is the Open/Closed Principle?
Ans:-   Open for extension but closed for modification. We should be able to add new functionality without changing existing code.
## Q10. What is the difference between == and is?
Ans:-   == is used to check data or values of two object and is used to check both object have same references or not.
## Q11. What is the purpose of the sudo command?
Ans:-   sudo command is used to run a command with administrative power.
## Q12. What are the function types Based on Arguments and Return Values?
Ans:-   
- Function with No Arguments and No Return Value
- Function with Arguments but No Return Value
- Function with No Arguments but a Return Value
- Function with Arguments and a Return Value
## Q13. What is DIP?
Ans:-   High-level modules should not depends on low-level modules. Both should depend on abstractions means high-level module have abstract method and those abstract method extends by low-level module. So, low-level module can give their own implementation.
