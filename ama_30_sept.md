
# AMA Questions and Answers

## What is Promise Chaining?
### Answer:

Promise chaining means executing multiple asynchronous operations one after another using `.then()`. Each `.then()` returns a new Promise.

## What is `D` in SOLID?
### Answer:

`D` stands for Dependency Inversion Principle (DIP). High-level modules should depend on abstractions, not concrete implementations.

## What is Flexbox?
### Answer:

Flexbox is a CSS layout system used to arrange and align elements efficiently in rows or columns.

## What is Hoisting?
### Answer:

Hoisting is JavaScript's behavior where declarations are processed before the code is executed, making them available earlier in their scope.

## What does `initial-scale=1.0` mean in HTML?
### Answer:
It sets the webpage's initial zoom level to 100% on mobile devices.


## Why is UTF-8 preferred?
### Answer:

UTF-8 supports almost all characters and languages, is compatible with ASCII, and is widely supported on the web.

## What is the difference between render and redirect?
### Answer:

- render(): Displays an HTML template directly in the current request. It does not change the URL.
- redirect(): Sends the user to a different URL/view and the browser makes a new request.

## What is a 500 Error?
### Answer:

HTTP 500 Internal Server Error means the server encountered an unexpected problem while processing the request.

## What is `on_delete=CASCADE`?
### Answer:

In Django, `on_delete=CASCADE` means when a parent object is deleted, its related child objects are also automatically deleted.

## What is the JavaScript Engine Used by Chrome?
### Answer:

Google Chrome uses the V8 JavaScript engine.
